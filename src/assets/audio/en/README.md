# English letter clips

Drop one clip per letter here, named after the letter id. Supported: `.m4a`, `.mp3`, `.wav`, `.aac`, `.ogg`.

```
a  b  c  d  e  f  g  h  i  j  k  l  m  n  o  p  q  r  s  t  u  v  w  x  y  z
```

e.g. `a.m4a` → say *"A. A is for Apple."* (the example word is shown on the letter card).
Any letter without a clip uses the device's voice. Generate them all on a Mac with
`scripts/make_letter_audio_mac.sh`.
